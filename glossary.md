# Glossary

How people talk at Fernway.

**Account vs venue**
One account can have many venues. Billing is per venue; contracts are per account. New hires mix these up constantly.

**Pay rules**
The per-country break and overtime configuration set during onboarding. See `processes/customer-onboarding.md`.

**The importer**
The CSV staff-import tool. It has a known problem with some files; see `runbooks/02-importer-failures.md`.

**T2L (time to live)**
Contract signed → first schedule published. Fernway's main onboarding metric. Typical T2L today is 1–3 days.

**Ghost shift**
A published shift nobody claimed. The single most common support complaint.

**Friday freeze**
The no-deploys-on-Friday rule (team rule 5). See `processes/releases.md`.

**Mara-check**
A pricing exception that needs the CEO, Mara Voss. Anything below list price (€39 per venue per month, 15% off for annual prepay) is a Mara-check.

**Activation**
⚠️ **Undefined: three conflicting meanings in use.** Everyone uses the word; nobody has defined it.
- Sales: first published schedule.
- Lukas Weber (Customer Success): a full week scheduled.
- The Metabase dashboard: something else again.

Say which meaning you mean. See [open-questions.md](open-questions.md#2-what-activation-means).
