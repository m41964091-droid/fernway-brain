# Runbook 04: Ship a release

**Process:** `processes/releases.md`

## Steps

1. Make sure the work has a Linear ticket.
2. Open a pull request for it.
3. Ask Ana Silva to test it on staging. If staging needs a reset, see `runbooks/03-reset-staging.md`.
4. Deploy on a Tuesday or Thursday.
5. **Never deploy on a Friday** (Friday freeze).
